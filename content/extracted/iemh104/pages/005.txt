4.3 Factorisation of Algebraic Expressions Using 
Identities
The identity (a + b)2
 = a2
 + 2ab + b2
 can also be used to find factors of 
some algebraic expressions.
Example 5: Consider the algebraic expression x2
 + 4x + 4. 
We observe that
x2
 = (x)2
, 4 = 22
 and 4x = 2(2)(x).
Hence, x2
 + 4x + 4 = x2
 + 2(x)(2) + 22
 can be compared with a2
 + 2(a)(b) + b2
, 
where a = x and b = 2.
We conclude that x2
 + 4x + 4 = (x + 2)2
. Therefore, we can say that 
(x + 2) is a factor of x2
 + 4x + 4.
Example 6: Let us try to find factors of another algebraic expression:
36x2

Writing this in the form a2

36x2

where a = 6x and b = 1. Therefore, 36x2
 + 12x + 1 = (6x + 1)2
.
Thus (6x + 1) is a factor of 36x2
 + 12x + 1.

[p.81-82] 4.1 The Notion of Letter-Numbers
Example 1: Shabnam is 3 years older than Aftab. When Aftab's age 10 years, Shabnam's age will be 13 years. Now Aftab's age is 18 years, what will Shabnam's age be?
Shabnam's age = Aftab's age + 3. Let a = Aftab's age, s = Shabnam's age. s = a + 3.
If a is 23, s = 23 + 3 = 26 years.
Letters such as a and s used to represent numbers are called letter-numbers. Expressions containing letter-numbers, such as a + 3, are called algebraic expressions.
Aftab's age = Shabnam's age - 3, i.e. a = s - 3 (3 less than s). Use this to find Aftab's age if Shabnam's age is 20.

Example 2: Parthiv makes matchstick L patterns, each L has 2 matchsticks. 5 Ls need 5×2. 7 Ls need 7×2. 45 Ls need 45×2. Number of matchsticks = 2 × Number of L's. Using n for number of L's: expression is 2×n.

4.2 Revisiting Arithmetic Expressions
Swapping (adding numbers in any order) and grouping (adding numbers by grouping conveniently) don't change value. Brackets with negative sign outside; distributive property (multiple of sum = sum of multiples).
Evaluate: 1. 23-10×2 = 23+(-20) = 3
2. 83+28-13+32 = 130 (group: 83+28=... ; -13+32... ; total 70+60=130)
3. 34-14+20 = 40
4. 42+15-(8-7) = 56
5. 68-(18+13): two ways -> 68+-(18+13) = 68-31 = 37; or 68-18-13 = 50-13=37
6. 7×4+9×6 = 28+54 = 82
7. 20+8×(16-6) = 20+80 = 100

[p.86] 4.3 Omission of the Multiplication Symbol
Sequence 4,8,12,16,20,24,28... = multiples of 4. 3rd term = 4×3. 29th term = 4×29. nth term = 4×n = 4n (number first, then letter, multiplication sign dropped).
7k when k=4: 7×4=28.
5m+3 when m=2: 5×2+3=13.
